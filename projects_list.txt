Power BI Interview Questions Asked in Wipro:

Q1: How do you create relationships between tables in Power BI?
I use the model view to drag and drop fields—usually the primary key to the foreign key. I check cardinality and keep relationships single-direction unless needed.

Q2: Difference between star and snowflake schema?
Star schema has denormalized dimensions—better for performance. Snowflake is normalized—saves space but is slower. I prefer star for Power BI.

Q3: How do you calculate YoY growth in DAX?
I use SAMEPERIODLASTYEAR with CALCULATE to compare current and previous year, then apply DIVIDE to get the growth percentage.

Q4: CALCULATE vs FILTER in DAX?
FILTER creates a table with row-level logic. CALCULATE changes context—it can wrap FILTER to apply logic before computing a measure.

Q5: How to create a dynamic date range slicer?
I create a disconnected table with options like “Last 7 Days”, “This Month” and use a measure with SWITCH and TODAY() to adjust filters dynamically.

Q6: What if a visual shows incorrect data?
I check relationships, filters, and DAX logic. Also, I verify column granularity—wrong joins or filters often cause issues.

Q7: How do you optimize a slow Power BI report?
I reduce visuals per page, remove unnecessary columns, use star schema, turn off auto date/time, and use optimized DAX. Aggregations help too.

Q8: How do you use Performance Analyzer?
I open it from the View tab, click “Start Recording,” and interact with visuals. It shows where time is spent—DAX, visual rendering, or query time.

Q9: Handling complex transformations in Power Query?
I break them into steps, use staging queries, and avoid row-by-row operations. I also prefer native database queries if possible.

Q10: Difference between merge and append in Power Query?
Append stacks rows (like UNION), used for similar tables.
Merge joins columns from two tables (like JOIN in SQL).

Q11: How do you implement Row-Level Security (RLS)?
I create roles in Power BI Desktop using DAX filters (like [Region] = USERNAME()), publish the report, and assign roles in the Power BI Service.

Q12: What is incremental refresh and how do you set it up?
It loads only new and changed data. I add RangeStart and RangeEnd parameters, filter the date column in Power Query, then configure it in Power BI Service.

 Clearly define what YOU did — data collection, cleaning, analysis, visualization, etc.
